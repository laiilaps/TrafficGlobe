Datenschutz

Diese Seite zeigt, woher Verbindungen zu diesem Server kommen. Die IP-Adressen dafür stammen aus den normalen Server-Logs. Sie werden lokal auf dem Server in einen ungefähren Ort umgewandelt, es wird dafür nichts an Dritte gesendet. Angezeigt wird nur dieser grobe Ort, nie eine IP-Adresse. Die Logs werden wie bei jedem Server in regelmäßigen Abständen automatisch gelöscht.

Passwörter, Benutzernamen, Accounts, E-Mail-Adressen oder ähnliche Daten haben damit nichts zu tun und werden dafür nicht verwendet. Die Anzeige ist anonym.
